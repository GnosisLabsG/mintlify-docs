## Chat Widget (Recommended)

The chat widget appears as a floating bubble that visitors can click to start chatting - perfect for customer support.

### Getting Your Widget Code

<Steps>
  <Step title="Access Embed Settings">
    Go to **Integration** → **Embed** in your Mind-e dashboard
  </Step>
  <Step title="Select Chat Box Embed">
    Click on the **Chat Box Embed** tab
  </Step>
  <Step title="Copy the Script">
    Click **Copy** to get your unique widget script
  </Step>
</Steps>

### Installation

Add the script code just before the closing `</body>` tag in your HTML:

```html
<script>
(function(){
  if(!window.mindeChat||!window.mindeChat("getState")==="initialized"){
    window.mindeChat=(...args)=>{
      if(!window.mindeChat.q){window.mindeChat.q=[]}
      window.mindeChat.q.push(args)
    };
    const script=document.createElement("script");
    script.src="https://mind-e.co/embed/chat-widget.js";
    script.id="b29c2c13-ce50-4da9-84f9-dcd715d9da5a";
    script.domain="mind-e.co";
    document.body.appendChild(script);
  }
  if(document.readyState==="complete"){onLoad()}
  else{window.addEventListener("load",onLoad)}
})();
</script>
```

<Note>
  Replace the `script.id` with your actual agent ID from the dashboard
</Note>

### Widget Features

- **24/7 Availability** - Always ready to help your visitors
- **Mobile Responsive** - Works perfectly on all devices  
- **Auto-positioning** - Appears in bottom-right corner by default
- **No Installation** - Visitors don't need to install anything

## Iframe Embed

Embed a full chat interface directly into your webpage content.

### Getting Your Iframe Code

<Steps>
  <Step title="Access Embed Settings">
    Go to **Integration** → **Embed** in your Mind-e dashboard
  </Step>
  <Step title="Select Iframe Embed">
    Click on the **iframe Embed** tab
  </Step>
  <Step title="Copy the Code">
    Click **Copy** to get your iframe code
  </Step>
</Steps>

### Installation

```html
<iframe
  src="https://mind-e.co/embed/chat.php?id=b29c2c13-ce50-4da9-84f9-dcd715d9da5a"
  width="100%"
  style="height: 100%; min-height: 700px"
  frameborder="0">
</iframe>
```

## Common Issues & Solutions

<AccordionGroup>
  <Accordion title="Widget not appearing" icon="alert-triangle">
    - Ensure script is placed before `</body>` tag
    - Check that your agent ID is correct
    - Verify no browser extensions are blocking scripts
    - Test in incognito mode
  </Accordion>

  <Accordion title="Iframe not loading" icon="square">
    - Verify the iframe src URL is correct
    - Ensure iframe has sufficient height (minimum 400px)
    - Check for Content Security Policy restrictions
    - Test the direct URL in a new browser tab
  </Accordion>

  <Accordion title="Agent not responding" icon="message-x">
    - Check agent status in dashboard (should be active)
    - Verify agent has knowledge sources configured
    - Test agent in Playground first
    - Look for error messages in browser console
  </Accordion>
</AccordionGroup>
