### Prerequisites

<Warning>
  **WhatsApp integration requires a verified WhatsApp Business account.** Your business phone number will be used as the contact point for your AI agent.
</Warning>

You'll need:
- Verified WhatsApp Business account
- Business phone number
- Facebook Business Manager account

### Setup Process

<Steps>
  <Step title="Access Integration">
    Go to **Integration** → **Connect** in your Mind-e dashboard
  </Step>
  <Step title="Connect WhatsApp">
    Click **Connect** next to WhatsApp
  </Step>
  <Step title="Verify Business Account">
    Complete Facebook Business Manager verification
  </Step>
  <Step title="Authorize Access">
    Allow Mind-e to manage your WhatsApp messages
  </Step>
  <Step title="Configure Settings">
    Set welcome messages and business hours
  </Step>
</Steps>

## Telegram Integration

Connect your AI agent to Telegram and chat with users through this popular messaging platform.

### Features

<CardGroup cols={3}>
  <Card title="Global Reach" icon="globe">
    Available worldwide without restrictions
  </Card>
  <Card title="Group Chat Capabilities" icon="users">
    Add your bot to group conversations
  </Card>
  <Card title="Bot-Friendly Ecosystem" icon="bot">
    Rich features designed for bots
  </Card>
</CardGroup>

### Prerequisites

<Info>
  **Telegram integration uses Telegram's Bot API.** You'll need to create a bot through BotFather and get an API token.
</Info>

You'll need:
- Telegram account
- Bot token from BotFather
- Basic understanding of bot setup

### Setup Process

<Steps>
  <Step title="Create Telegram Bot">
    Open Telegram and message **@BotFather**
  </Step>
  <Step title="Get Bot Token">
    Follow BotFather instructions to create your bot and get API token
  </Step>
  <Step title="Connect to Mind-e">
    Go to **Integration** → **Connect** and click **Connect** next to Telegram
  </Step>
  <Step title="Enter Bot Token">
    Paste your bot token from BotFather
  </Step>
  <Step title="Configure Bot">
    Set up commands and responses
  </Step>
</Steps>

### Creating Your Telegram Bot

<Tabs>
  <Tab title="Step 1: Find BotFather">
    1. Open Telegram
    2. Search for **@BotFather**
    3. Start a conversation
  </Tab>
  
  <Tab title="Step 2: Create Bot">
    1. Send `/newbot` command
    2. Choose a name for your bot
    3. Choose a username ending in "bot"
    4. Save the API token provided
  </Tab>
  
  <Tab title="Step 3: Configure">
    1. Set bot description with `/setdescription`
    2. Add bot commands with `/setcommands`
    3. Upload bot profile picture with `/setuserpic`
  </Tab>
</Tabs>

### Learn More

<Info>
  For comprehensive bot creation guide, see [Telegram Bot documentation](https://core.telegram.org/bots).
</Info>

## Troubleshooting

<AccordionGroup>
  <Accordion title="WhatsApp connection failed" icon="alert-triangle">
    - Verify WhatsApp Business account is approved
    - Check Facebook Business Manager access
    - Ensure business phone number is verified
    - Contact WhatsApp support if issues persist
  </Accordion>

  <Accordion title="Telegram bot not responding" icon="bot">
    - Verify bot token is correct and active
    - Check bot permissions and settings
    - Ensure webhook is properly configured
    - Test bot directly with BotFather
  </Accordion>

  <Accordion title="Messages not syncing" icon="refresh-cw">
    - Check internet connection stability
    - Verify agent is active in dashboard
    - Look for error messages in integration settings
    - Contact support for persistent issues
  </Accordion>
</AccordionGroup>

- Follow Telegram Bot API terms
- Respect group chat rules
- Implement rate limiting
