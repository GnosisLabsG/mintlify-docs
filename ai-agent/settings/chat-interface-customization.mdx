## Overview

Customize how your chat interface looks to match your brand. Changes apply to web embeds and share links.

<Info>
  Use the live preview to see changes in real-time as you customize.
</Info>

## Avatars

### Profile Avatar
Upload an avatar for the chat header and profile information.
- **Recommended size:** 250x250 pixels
- **Max file size:** 2MB
- **Formats:** JPG, PNG, GIF

### Chat Avatar  
Avatar that appears next to the agent's messages in the chat.
- **Recommended size:** 250x250 pixels
- **Max file size:** 2MB
- **Formats:** JPG, PNG, GIF

## Messages

### Welcome Message
The initial message displayed when users start a chat.

```
Hello! I'm your AI assistant. How can I help you today?
```

### Input Placeholder Text
Placeholder text that appears in the chat input field.

```
Type your message here...
```

## Colors & Styling

### Primary Color
Choose between solid color or gradient for the chat header and bubble.

<Tabs>
  <Tab title="Solid Color">
    Single color for consistent branding
  </Tab>
  <Tab title="Gradient">
    Two-color gradient for modern look
    - **Start Color:** Beginning of gradient
    - **End Color:** End of gradient
  </Tab>
</Tabs>

### User Message Color
Customize the color for user messages in the chat.
- Choose solid color or gradient
- Applies to user message bubbles

### Chat Bubble Icon
Upload a custom icon for the floating chat button.
- **Recommended size:** 25x25 pixels
- **Max file size:** 1MB  
- **Formats:** JPG, PNG, GIF, SVG

## Typography

### Primary Font
Choose the font family used throughout the chat interface.
- Applies to all text including messages, headers, and input fields
- **Default:** Poppins

### Text Direction
Set text direction for the chat interface.

<CardGroup cols={2}>
  <Card title="Left to Right (LTR)" icon="arrow-right">
    For English, French, Spanish, etc.
  </Card>
  <Card title="Right to Left (RTL)" icon="arrow-left">
    For Arabic, Hebrew, Persian, etc.
  </Card>
</CardGroup>

<Note>
  Text direction affects message alignment, input field direction, and overall chat layout.
</Note>

## Best Practices

- **Brand Consistency:** Use colors that match your website
- **Readability:** Ensure good contrast between text and backgrounds  
- **File Sizes:** Keep images under recommended sizes for fast loading
- **Testing:** Preview changes before saving

<Warning>
  Always save your settings after making changes. Updates apply to all active integrations.
</Warning>
