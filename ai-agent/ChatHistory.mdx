## Filter Conversations

Find specific conversations using filters.

### Date Range

Select a time period to view conversations from specific dates:
- Last 7 days
- Last 30 days
- Custom date range

### Source

Filter conversations by where they originated:

- **Mind-e site** - Conversations from your main website
- **iFrame** - Embedded chat widget conversations
- **Chatbox** - Chat widget conversations 
- **WhatsApp** - WhatsApp integration chats
- **Telegram** - Telegram bot conversations
- **API** - Direct API conversations
- **All Sources** - View conversations from all channels

### Apply Filters

Click "Apply Filters" to update the conversation list based on your selected criteria.

---

## Conversation List

View all conversations in chronological order.

### Conversation Details

Each conversation shows:
- **Timestamp** - When the conversation started
- **Message Preview** - First message or conversation summary
- **Source Label** - Which platform the conversation came from
- **Language** - Detected conversation language

### Viewing Conversations

**Select Conversation**: Click any conversation from the list to view the full chat.

**Conversation View**: See the complete conversation thread with:
- User messages and AI responses
- Timestamps for each message
- Source information and context
