## Overview

Mind-e provides powerful APIs for creating personalized AI agents with user-specific knowledge bases. Perfect for schools, organizations, and platforms that need to provide personalized AI experiences to their users.

### Key Features

- <Icon icon="database" /> **User-Specific Databases** - Create isolated knowledge bases for each user
- <Icon icon="file" /> **Document Management** - Upload and manage documents (PDF, Word, HTML, Text)  
- <Icon icon="shield-check" /> **Identity Verification** - Secure user authentication without storing passwords
- <Icon icon="check" /> **Vector Search** - AI-powered semantic search across user documents
- <Icon icon="clock" /> **Real-time Processing** - Background document processing with status tracking

All API requests require authentication using API keys.

### Getting API Keys

<Steps>
  <Step title="Login">

  </Step>
  <Step title="Navigate">
    Navigate to API Keys section
  </Step>

    Store your API key securely
  </Step>

### Using API Keys

Include your API key in the Authorization header:

```http
Authorization: Bearer sk-your-api-key-here
```

### API Key Permissions

- **user_databases**: Create and manage user databases
- **user_data**: Upload and manage user documents

### Base URLs

- **Production**: `https://mind-e.co/api/`
- **User Databases**: `https://mind-e.co/api/user-databases/`
- **User Data**: `https://mind-e.co/api/user-data/`

## API Endpoints

### User Database Management

- **POST** `/user-databases/agents/{agent_id}/users/{user_id}/database` - Create user database (max 100 per agent)
- **GET** `/user-databases/agents/{agent_id}/users/{user_id}/database` - Get user database info  
- **DELETE** `/user-databases/agents/{agent_id}/users/{user_id}/database` - Delete user database
- **GET** `/user-databases/agents/{agent_id}/users` - List all user databases for agent
- **GET** `/user-databases/agents/{agent_id}/quota` - Get quota information for agent
- **GET** `/user-databases/agents/{agent_id}/debug` - Get debug information for agent

### User Data Upload

- **POST** `/user-data/agents/{agent_id}/users/{user_id}/documents` - Upload document to user database
- **GET** `/user-data/agents/{agent_id}/users/{user_id}/documents` - List user documents
- **DELETE** `/user-data/agents/{agent_id}/users/{user_id}/documents?document_id={id}` - Delete user document
- **GET** `/user-data/agents/{agent_id}/users/{user_id}/status` - Get document processing status

### HTTP Status Codes

| Code | Meaning |
|------|---------|
| 200 | Success |
| 201 | Created |
| 204 | No Content (successful deletion) |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 409 | Conflict (resource already exists) |
| 429 | Too Many Requests (quota exceeded) |
| 500 | Internal Server Error |

## User Databases API

Manage user-specific knowledge databases for your agents.

### Create User Database

Creates a new isolated database for a user.

**Endpoint**: `POST /user-databases/agents/{agent_id}/users/{user_id}/database`

**Parameters**:
- `agent_id` (string): Your agent ID from Mind-e dashboard
- `user_id` (string): Unique identifier for the user (1-50 characters, alphanumeric + underscore/hyphen/dot)

<CodeGroup>
```bash cURL
curl -X POST "https://mind-e.co/api/user-databases/agents/95ed0653-44d2-4c32-8add-0e7022691068/users/student_123/database" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json"
```

```javascript JavaScript

  headers: {
    'Authorization': 'Bearer sk-your-api-key',
```

## User Data API

Upload and manage documents in user-specific databases.

### Upload Document

Uploads a document to a user's database for processing.

**Endpoint**: `POST /user-data/agents/{agent_id}/users/{user_id}/documents`

**Supported Formats**: PDF, DOC, DOCX, TXT, HTML, HTM  
**Max File Size**: 10MB

<CodeGroup>
```bash cURL
curl -X POST "https://mind-e.co/api/user-data/agents/95ed0653-44d2-4c32-8add-0e7022691068/users/student_123/documents" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "file=@student_schedule.pdf"
```

```javascript JavaScript
const formData = new FormData();
formData.append('file', fileInput.files[0]);

const response = await fetch('https://mind-e.co/api/user-data/agents/95ed0653-44d2-4c32-8add-0e7022691068/users/student_123/documents', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk-your-api-key'
  },
  body: formData
});
```


## Identity Verification System

Secure user authentication for personalized AI responses without storing passwords.

### How It Works

<Steps>
  <Step title="Server-side">
    Generate a hash using HMAC-SHA256 with your secret key
  </Step>
  <Step title="Client-side">
    Send user ID, hash, and optional metadata
  </Step>
  <Step title="Mind-e">
    Verifies the hash and provides personalized responses
  </Step>
</Steps>

### Generate User Hash

Use your agent's secret key to generate verification hashes:

<CodeGroup>
```javascript Node.js
const crypto = require('crypto');

function generateUserHash(userId, secretKey) {
    return crypto
        .createHmac('sha256', secretKey)
        .update(userId)
        .digest('hex');
}

// Usage
const userId = 'student_123';
const secretKey = 'your-secret-key-from-dashboard';
const userHash = generateUserHash(userId, secretKey);
```

```php PHP
function generateUserHash($userId, $secretKey) {
    return hash_hmac('sha256', $userId, $secretKey);
}

// Usage
$userId = 'student_123';
$secretKey = 'your-secret-key-from-dashboard';
$userHash = generateUserHash($userId, $secretKey);
```

```python Python
import hmac
import hashlib

def generate_user_hash(user_id, secret_key):
    return hmac.new(
        secret_key.encode(),
        user_id.encode(),
        hashlib.sha256
    ).hexdigest()

# Usage
user_id = 'student_123'
secret_key = 'your-secret-key-from-dashboard'
user_hash = generate_user_hash(user_id, secret_key)
```
</CodeGroup>

### Using Identity Verification in Chat

When making chat requests, include identity verification:

```javascript
// Chat request with verified identity
const chatRequest = {
    message: "When is my next exam?",
    user_id: "student_123",
    user_hash: userHash,
    user_metadata: {
        class: "10A",
        semester: "fall2024"
    }
};
```

### Benefits

- ✅ **No passwords stored** - Only cryptographic hashes
- ✅ **Per-request verification** - Each interaction is verified  
- ✅ **Automatic data isolation** - Users only access their own data
- ✅ **Audit trail** - All access is logged with user context

## Getting Started

## Example Integration

### School Management System Integration

<CodeGroup>
```javascript Complete Example
// 1. Create databases for all students
async function createStudentDatabases(students) {
    for (const student of students) {
        await fetch(`https://mind-e.co/api/user-databases/agents/${AGENT_ID}/users/${student.id}/database`, {
            method: 'POST',
            headers: {
                'Authorization': `Bearer ${API_KEY}`
            }
        });
    }
}

// 2. Upload student-specific documents
async function uploadStudentSchedule(studentId, scheduleFile) {
    const formData = new FormData();
    formData.append('file', scheduleFile);
    
    await fetch(`https://mind-e.co/api/user-data/agents/${AGENT_ID}/users/${studentId}/documents`, {
        method: 'POST',
        headers: {
            'Authorization': `Bearer ${API_KEY}`
        },
        body: formData
    });
}

// 3. Generate verification hash for student
function generateStudentHash(studentId) {
    return crypto
        .createHmac('sha256', SECRET_KEY)
        .update(studentId)
        .digest('hex');
}

// 4. Student chat with verification
async function studentChat(studentId, message) {
    const userHash = generateStudentHash(studentId);
    
    const response = await fetch(`${CHAT_ENDPOINT}`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            message,
            user_id: studentId,
            user_hash: userHash,
            user_metadata: {
                role: 'student',
                school_id: 'school_123'
            }
        })
    });
    
    return response.json();
}
```
</CodeGroup>
