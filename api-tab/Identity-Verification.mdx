## What is Identity Verification?

Identity Verification is a security feature that allows your AI agent to securely identify and personalize interactions with users. When implemented, your agent can:

- **Verify user identities** to prevent impersonation
- **Access user information** like names, emails, and preferences  
- **Provide personalized responses** based on verified user data
- **Maintain secure conversations** with authenticated users

### Step 2: Implement Server-Side Hash Generation

You must generate user hashes on your server using HMAC-SHA256:

<CodeGroup>
```javascript Node.js
const crypto = require('crypto');

function generateUserHash(userId, secretKey) {
    return crypto
        .createHmac('sha256', secretKey)
        .update(userId)
        .digest('hex');
}

// Usage
const userId = 'user_12345';
const secretKey = 'your-secret-key-from-dashboard';
const userHash = generateUserHash(userId, secretKey);
```

```php PHP
function generateUserHash($userId, $secretKey) {
    return hash_hmac('sha256', $userId, $secretKey);
}

// Usage
$userId = 'user_12345';
$secretKey = 'your-secret-key-from-dashboard';
$userHash = generateUserHash($userId, $secretKey);
```

```python Python
import hmac
import hashlib

def generate_user_hash(user_id, secret_key):
    return hmac.new(
        secret_key.encode(),
        user_id.encode(),
        hashlib.sha256
    ).hexdigest()

# Usage
user_id = 'user_12345'
secret_key = 'your-secret-key-from-dashboard'
user_hash = generate_user_hash(user_id, secret_key)
```
</CodeGroup>

## User Metadata

User metadata provides additional context about users to the AI.

### Recommended Fields

| Field | Description | Example |
|-------|-------------|---------|
| **name** | User's display name | "Sarah Johnson" |
| **email** | Email address | "sarah@company.com" |
| **role** | User's role/position | "Manager", "Customer" |
| **plan** | Subscription level | "Premium", "Basic" |
| **company** | Company name | "Acme Corporation" |
| **department** | Department/team | "Engineering", "Sales" |

### Example Metadata

```json
{
    "name": "Sarah Johnson",
    "email": "sarah@company.com",
    "role": "Product Manager",
    "plan": "Premium",
    "company": "Tech Corp",
    "department": "Product",
    "preferences": {
        "language": "en",
        "timezone": "UTC-5"
    }
}
```

### Limitations

- Maximum 1000 characters total (JSON stringified)
- Must be valid JSON format
- No sensitive data (passwords, tokens, etc.)

## How It Works

<Steps>
  <Step title="Server-Side Hash Generation">
    Generate a cryptographic hash using the user's ID and your secret key:
    ```
    HMAC-SHA256(user_id, secret_key) = user_hash
    ```
  </Step>
  
  <Step title="Client-Side Verification">
    Send three pieces of information to Mind-e:
    - **User ID**: The user's unique identifier
    - **User Hash**: The secure hash generated on your server
    - **User Metadata**: Additional user information (optional)
  </Step>
  
  <Step title="Mind-e Validation">
    Mind-e verifies the hash matches the user ID using your secret key. If valid, the AI gets access to the user's information.
  </Step>
</Steps>

## Complete Implementation Example

### Server-Side (Node.js)

```javascript
const express = require('express');
const crypto = require('crypto');

const app = express();
const SECRET_KEY = process.env.MIND_E_SECRET_KEY;

app.post('/api/generate-user-hash', authenticate, (req, res) => {
    const userId = req.user.id;
    
    const userHash = crypto
        .createHmac('sha256', SECRET_KEY)
        .update(userId)
        .digest('hex');
    
    res.json({
        user_id: userId,
        user_hash: userHash,
        user_metadata: {
            name: req.user.name,
            email: req.user.email,
            role: req.user.role
        }
    });
});
```

### Client-Side

```javascript
async function setUserIdentity(userId) {
    try {
        const response = await fetch('/api/generate-user-hash', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' }
        });
        
        const data = await response.json();
        
        mindeChat('identify', {
            user_id: data.user_id,
            user_hash: data.user_hash,
            user_metadata: data.user_metadata
        });
        
    } catch (error) {
        console.error('Failed to set user identity:', error);
    }
}
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Hash Verification Fails">
    **Common Causes:**
    - Secret key mismatch
    - Incorrect hash algorithm  
    - User ID mismatch between client and server
    
    **Solutions:**
    - Verify secret key is copied exactly from Mind-e dashboard
    - Ensure using HMAC-SHA256 algorithm
    - Check user ID is identical in all requests
  </Accordion>

  <Accordion title="Widget Not Loading Identity">
    **Solutions:**
    - Ensure widget is fully loaded before calling identify
    - Check browser console for JavaScript errors
    - Verify all required parameters are provided
  </Accordion>

  <Accordion title="Metadata Issues">
    **Problem:** Metadata too large (>1000 characters)
    
    **Solution:** Reduce metadata size by removing unnecessary fields
    
    **Problem:** Invalid JSON in metadata
    
    **Solution:** Validate JSON before sending:
    ```javascript
    try {
        JSON.stringify(userMetadata);
    } catch (error) {
        console.error('Invalid metadata JSON:', error);
    }
    ```
  </Accordion>
</AccordionGroup>
