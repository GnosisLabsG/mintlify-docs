## Overview

Bulk document upload allows you to distribute files to multiple user databases efficiently:

| Description | Method | Endpoint |
|-------------|--------|----------|
| Individual operations (existing) | **POST/GET/DELETE** | `/agents/{agent_id}/users/{user_id}/documents` |
| Bulk upload (new) | **POST** | `/agents/{agent_id}/users/bulk-documents` |
| Bulk status (new) | **GET** | `/agents/{agent_id}/users/bulk-documents` |

## Bulk Document Upload

**Method:** `POST`  
**Endpoint:** `/api/user-data/agents/{agent_id}/users/bulk-documents`

### Request Format
**Content-Type:** `multipart/form-data`

### Form Fields

**Files**
Upload files with unique field names:
- `file1` - First document
- `file2` - Second document  
- `curriculum_pdf` - Curriculum document
- `homework_doc` - Homework document
- etc.

**Config (Required)**
JSON configuration in the `config` form field:

```json
{
  "mappings": [
    {
      "file_key": "curriculum_pdf",
      "user_ids": ["student1", "student2", "student3", "student4", "student5"]
    },
    {
      "file_key": "homework_doc", 
      "user_ids": ["student1", "student2"]
    }
  ],
  "options": {
    "continue_on_error": true,
    "duplicate_handling": "skip",
    "max_files_per_user": 20,
    "validate_databases_first": true
  }
}
```

### Upload Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `continue_on_error` | boolean | `true` | Continue processing even if some uploads fail |
| `duplicate_handling` | string | `"skip"` | How to handle duplicate files: "skip", "overwrite", "error" |
| `max_files_per_user` | integer | `20` | Maximum files per user in one batch |
| `validate_databases_first` | boolean | `true` | Check all user databases exist before starting |

Upload `curriculum.pdf` to 10 students:

```bash
curl -X POST "https://mind-e.co/api/user-data/agents/school-agent/users/bulk-documents" \
  -H "Authorization: Bearer your-api-key" \
  -F "curriculum=@curriculum.pdf" \
  -F 'config={
    "mappings": [
      {
        "file_key": "curriculum",

      "duplicate_handling": "skip"

```

## Complete JavaScript Example

```javascript
class BulkDocumentManager {
  constructor(apiKey, agentId) {
    this.apiKey = apiKey;
    this.agentId = agentId;
    this.baseUrl = 'https://mind-e.co/api/user-data';
  }

  async uploadBulkDocuments(files, mappings, options = {}) {
    const formData = new FormData();
    
    // Add files
    Object.entries(files).forEach(([key, file]) => {
      formData.append(key, file);
    });
    
    // Add config
    formData.append('config', JSON.stringify({
      mappings,
      options: {
        continue_on_error: true,
        duplicate_handling: "skip",
        ...options
      }
    }));

    const response = await fetch(`${this.baseUrl}/agents/${this.agentId}/users/bulk-documents`, {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${this.apiKey}` },
      body: formData
    });
    
    return response.json();
  }

  async getBulkStatus(userIds) {
    const response = await fetch(`${this.baseUrl}/agents/${this.agentId}/users/bulk-documents`, {
      method: 'GET',
      headers: {
        'Authorization': `Bearer ${this.apiKey}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ user_ids: userIds })
    });
    
    return response.json();
  }

  async waitForProcessing(userIds, timeout = 300000) {
    const startTime = Date.now();
    
    while (Date.now() - startTime < timeout) {
      const status = await this.getBulkStatus(userIds);
      
      const allCompleted = status.data.users_status.every(user => 
        user.status_summary.processing === 0
      );
      
      if (allCompleted) {
        return status;
      }
      
      await new Promise(resolve => setTimeout(resolve, 5000));
    }
    
    throw new Error('Processing timeout');
  }
}

// Usage example
const manager = new BulkDocumentManager('your-api-key', 'school-agent');

// Upload curriculum to all students
async function distributeCurriculum() {
  const students = ['student1', 'student2', 'student3', 'student4', 'student5'];
  const files = {
    curriculum: new File([curriculumData], 'curriculum.pdf'),
    syllabus: new File([syllabusData], 'syllabus.pdf')
  };
  
  const mappings = [
    {
      file_key: 'curriculum',
      user_ids: students
    },
    {
      file_key: 'syllabus', 
      user_ids: students.slice(0, 3) // Only first 3 students
    }
  ];

  try {
    const result = await manager.uploadBulkDocuments(files, mappings);
    console.log(`Upload started: ${result.data.successful_uploads} successful`);
    
    // Wait for processing
    const finalStatus = await manager.waitForProcessing(students);
    console.log('All documents processed successfully');
    
    return finalStatus;
  } catch (error) {
    console.error('Upload failed:', error);
    throw error;
  }
}
```

## Error Handling

Handle upload failures and processing issues:

```javascript
async function robustBulkUpload(files, mappings) {
  try {
    const result = await manager.uploadBulkDocuments(files, mappings);
    
    // Check for upload failures
    if (result.data.failed_uploads > 0) {
      console.log('Some uploads failed:');
      result.data.results.forEach(fileResult => {
        fileResult.user_results
          .filter(ur => !ur.success)
          .forEach(ur => console.log(`${ur.user_id}: ${ur.error}`));
      });
    }
    
    return result;
  } catch (error) {
    if (error.message.includes('file too large')) {
      console.log('File size exceeded. Split into smaller files.');
    } else if (error.message.includes('quota exceeded')) {
      console.log('Upload quota exceeded. Try again later.');
    }
    throw error;
  }
}
```

## Troubleshooting

**File Upload Failures**
- Check file sizes (max 10MB per file)
- Verify supported formats (PDF, DOC, DOCX, TXT, HTML)
- Ensure all target user databases exist

**Processing Delays**  
- Large files take 1-3 minutes to process
- Monitor status with bulk status endpoint
- Implement timeout handling for very large batches

**Quota Issues**
- Check file upload limits before bulk operations
- Process in smaller batches if approaching limits
- Monitor rate limits (10 requests/minute for bulk uploads)
