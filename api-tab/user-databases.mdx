</Info>

## Create User Database

Creates a new isolated database for a user.

**Endpoint**: `POST /user-databases/agents/{agent_id}/users/{user_id}/database`

### Parameters

- `agent_id` (string): Your agent ID from Mind-e dashboard
- `user_id` (string): Unique identifier for the user (1-50 characters, alphanumeric + underscore/hyphen/dot)

<CodeGroup>
```bash cURL
curl -X POST "https://mind-e.co/api/user-databases/agents/95ed0653-44d2-4c32-8add-0e7022691068/users/student_123/database" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json"
```

```javascript JavaScript

  headers: {
    'Authorization': 'Bearer sk-your-api-key',

});
```

## Delete User Database

Permanently deletes a user's database and all associated data.

<Warning>
This action cannot be undone. All user documents and data will be permanently deleted.
</Warning>

**Endpoint**: `DELETE /user-databases/agents/{agent_id}/users/{user_id}/database`

```bash
curl -X DELETE "https://mind-e.co/api/user-databases/agents/95ed0653-44d2-4c32-8add-0e7022691068/users/student_123/database" \
  -H "Authorization: Bearer sk-your-api-key"
```

### Response

```json
{
  "success": true,
  "message": "User database deleted successfully"
}
```

## Example: Complete Database Management

```javascript
// Complete example: Create database, check status, manage lifecycle
class UserDatabaseManager {
  constructor(apiKey, agentId) {
    this.apiKey = apiKey;
    this.agentId = agentId;
    this.baseUrl = 'https://mind-e.co/api/user-databases';
  }

  async createUserDatabase(userId) {
    const response = await fetch(`${this.baseUrl}/agents/${this.agentId}/users/${userId}/database`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${this.apiKey}`,
        'Content-Type': 'application/json'
      }
    });
    return response.json();
  }

  async getUserDatabase(userId) {
    const response = await fetch(`${this.baseUrl}/agents/${this.agentId}/users/${userId}/database`, {
      headers: { 'Authorization': `Bearer ${this.apiKey}` }
    });
    return response.json();
  }

  async deleteUserDatabase(userId) {
    const response = await fetch(`${this.baseUrl}/agents/${this.agentId}/users/${userId}/database`, {
      method: 'DELETE',
      headers: { 'Authorization': `Bearer ${this.apiKey}` }
    });
    return response.json();
  }

  async listAllDatabases() {
    const response = await fetch(`${this.baseUrl}/agents/${this.agentId}/users`, {
      headers: { 'Authorization': `Bearer ${this.apiKey}` }
    });
    return response.json();
  }

  async getQuota() {
    const response = await fetch(`${this.baseUrl}/agents/${this.agentId}/quota`, {
      headers: { 'Authorization': `Bearer ${this.apiKey}` }
    });
    return response.json();
  }
}

// Usage
const dbManager = new UserDatabaseManager('sk-your-api-key', 'your-agent-id');

// Create database for student
const result = await dbManager.createUserDatabase('student_123');
console.log('Database created:', result);

// Check quota
const quota = await dbManager.getQuota();
console.log('Remaining quota:', quota.data.quota.user_databases.remaining);
```

## Best Practices

### Database Naming
- Use consistent, meaningful user IDs
- Keep user IDs under 50 characters
- Use alphanumeric characters, underscores, hyphens, or dots only

### Quota Management
- Monitor quota usage regularly
- Implement cleanup procedures for inactive users
- Check quota before creating new databases

### Error Handling
```javascript
async function createDatabaseSafely(userId) {
  try {
    // Check quota first
    const quota = await dbManager.getQuota();
    if (quota.data.quota.user_databases.remaining === 0) {
      throw new Error('Database quota exceeded');
    }

    // Create database
    const result = await dbManager.createUserDatabase(userId);
    return result;
  } catch (error) {
    if (error.message.includes('already exists')) {
      // Database already exists, get existing one
      return await dbManager.getUserDatabase(userId);
    }
    throw error;
  }
}
```
